# Strategy

Positioning, proof, market and pricing documents, plus the operator practice
behind them. Every page in this directory is listed below once. Several pages
consolidate older strategy and outreach files; [STRATEGY_INDEX](./STRATEGY_INDEX.md)
maps each old file name to its new location. For the commercial summary, see
[COMMERCIAL_OVERVIEW](../COMMERCIAL_OVERVIEW.md) and
[WHY_ARAGORA](../WHY_ARAGORA.md). The full documentation map is in
[docs/README.md](../README.md).

Dates in the tables come from each page's own header. Strategy pages describe
the product and market when they were written; check the code and
[STATUS](../STATUS.md) before repeating a claim.
